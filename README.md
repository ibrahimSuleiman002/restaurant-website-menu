# Ember & Olive

A demo restaurant website for Ember & Olive, built with HTML, CSS, and JavaScript. Includes a home page, menu with categorized items and pricing, about section, gallery, reservations, and contact page — designed to be fast-loading and mobile responsive.

## Features
- Full-bleed photography sections with overlaid text
- Categorized menu with pricing (Rice, Fufu & Soup, and more)
- User account flow (sign up, login, logout, password reset, account/history deletion)
- Mobile-optimized, lightweight design

## Built with
- HTML, CSS, JavaScript
- Built and iterated using OpenAI Codex
